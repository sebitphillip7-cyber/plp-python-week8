# Personal Mini-Toolkit

## Project Description
The Personal Mini-Toolkit is a menu-driven Python program with three tools: a simple calculator, a to-do list manager, and a number guessing game.

## Tools Included
1. **Simple Calculator** — adds, subtracts, multiplies, and divides two numbers.
2. **To-Do List Manager** — lets users add, view, and remove tasks while the program is running.
3. **Number Guessing Game** — asks users to guess a secret number and gives higher/lower hints.

## Python Concepts Used
- Variables and input/output
- `if`, `elif`, and `else` conditionals
- `while` and `for` loops
- Lists and list methods such as `append()` and `pop()`
- Type conversion and input validation
- F-strings and comments

## How to Run
1. Install Python 3.
2. Open this folder in VS Code.
3. Open the VS Code terminal.
4. Run `python toolkit.py`.
5. Choose a tool from the menu.

## Project Reflection
The most challenging part of this project was making the three tools work together through one menu that keeps running until the user chooses to quit. The part that needed the most careful testing was handling user input and returning to the correct menu after each tool finished. I learned how to use a list to store tasks and update that list as tasks are added or removed. I also practised using loops to repeat menus and keep the guessing game running. Testing invalid choices helped me understand how conditionals can prevent a program from stopping unexpectedly. I am proud that I brought variables, input, conditionals, loops, and lists together in one useful program. With one more week, I would add the ability to save tasks to a file so they remain available after the program closes.
